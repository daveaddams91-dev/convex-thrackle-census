A census of convex thrackles: residue bound, wedge lemma, and the exact count 2^(n-1)-n of maximal thrackles

## Overview

`convex-thrackle-census` is a systems-level tool featuring lexical analysis, parsing, and execution pipelines designed for efficiency and correctness.

## Features

- Modular tokenizer and parser pipeline.
- Comprehensive test suite for language grammar and runtime operations.
- Performance benchmarks evaluating throughput and memory efficiency.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/convex-thrackle-census.git
cd convex-thrackle-census
pip install -r requirements.txt
```

Run tests:

```bash
pytest tests/
```
